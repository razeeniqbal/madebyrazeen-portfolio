------------------------------------------------------------------------

## 1. Product Vision

Portfolio V2 is the personal digital home of **Razeen Iqbal**.

It should not behave like a conventional developer portfolio, online
résumé, SaaS landing page, or collection of technology logos.

The portfolio should communicate a person who:

> **builds systems, experiments with ideas, continuously learns, and
> applies the same mindset to engineering and life.**

The experience combines:

**Engineering + AI + Data + Products + Experimentation + Learning +
Running + Personality**

The website should feel like a hybrid of:

-   engineering notebook
-   technical publication
-   personal laboratory
-   project archive
-   visual portfolio
-   running journal
-   personal website

The visitor should leave understanding not only **what Razeen has
built**, but also **how Razeen thinks**.

Visitors should understand that Razeen can work across:

-   data engineering
-   analytics
-   AI/ML
-   AI systems
-   product engineering
-   architecture
-   experimentation

The portfolio should be recognisable even if the visitor cannot see the

## 4. Non-Goals

Portfolio V2 must **not** become:

-   a generic developer portfolio
-   a résumé website
-   a SaaS landing page
-   a giant dashboard
-   a technology-logo showcase
-   a cartoon website
-   a cyberpunk interface
-   an AI-generated-looking landing page
-   a Dribbble concept with poor usability

The website must avoid excessive:

-   glassmorphism
-   glowing gradients
-   neon
-   purple/blue AI aesthetics
-   floating blobs
-   card grids
-   skill progress bars
-   logo walls
-   3D decoration
-   animation without purpose

## 9. Typography

Three typography roles are required.

### Display

Bold grotesk.

Used for hero statements, section titles, project names and major
statistics.

### Body

Neutral sans serif. Recommended: **Inter or equivalent.**

Used for paragraphs, project descriptions, navigation and supporting
content.

### Technical

Monospace. Recommended: **IBM Plex Mono or equivalent.**

Used for metadata, coordinates, dates, architecture labels, project
numbers, annotations, statistics and system states.

## 10. Grid System

The grid is part of the brand.

relationships.

It must **not** become visual noise.

Tablet and mobile should simplify the system instead of merely shrinking
it.

## 36. Motion System

Motion communicates **progress** rather than decoration.

Primary motion metaphor:

``` text
○ ─── ○ ─── ○ ─── ●
```

Possible interactions:

-   line drawing
-   node activation
-   progress movement
-   text reveal
-   diagram construction
-   image reveal
-   subtle parallax
-   data chart drawing
-   Mini Razeen micro-interactions

Avoid constant floating, excessive cursor effects, huge scroll-jacking,
slow page transitions and unnecessary 3D movement.

------------------------------------------------------------------------

## 37. Reduced Motion

Respect:

``` css
prefers-reduced-motion
```

Disable or simplify trajectory animations, parallax, animated charts,
character movement and page transitions.

Content must remain fully usable.
